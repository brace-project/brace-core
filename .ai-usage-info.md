# Brace Core

Brace Core provides the application framework and abstract HTTP interfaces, not a concrete HTTP backend. It is normally used together with [brace/mod-request-laminas](https://github.com/brace-project/brace-mod-request-laminas), which provides PSR-7 requests, query parameters, response factories and response emission.
Register `BraceRequestLaminasModule` from `Brace\Mod\Request\Zend` on your `BraceApp`.

## Streaming

Use `$app->responseFactory->createStreamedResponse($callback)` for general
streaming of raw output. The callback runs when the response is emitted.

For NDJSON streaming, use `$app->responseFactory->createNdjsonResponse($callback)` to
stream JSON objects from a controller; the callback receives
`Brace\Core\NdjsonStream` and sends each record with `$stream->send($data)`.
Return the response from the controller rather than writing output there.

- [PHP handler](https://github.com/brace-project/brace-mod-request-laminas/blob/main/examples/ndjson-handler.php)
- [JavaScript client](https://github.com/brace-project/brace-mod-request-laminas/blob/main/examples/ndjson-client.js)

Disable response buffering and compression in the web server/proxy.
The callback runs after HTTP headers are prepared; signal process failures
in the stream and treat a missing final result as an interrupted process.
See [server configuration](https://github.com/brace-project/brace-mod-request-laminas/blob/main/examples/NDjson%20Config.md).
